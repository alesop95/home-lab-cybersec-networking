# Introduzione

Facciamo una sintesi completa e descrittiva di ciò che devi sapere se stai considerando un contratto FTTH (fibra ottica “classica”, non FWA), con un focus sui punti di attenzione legali, costi, recesso, modem, ecc.

I punti a cui prestare massima attenzione sono:

- Prima di firmare, leggi il contratto completo, non solo la parte “commerciale”: verifica i dettagli su attivazione, rate e recesso.
- Se non sei sicuro di restare 24 mesi, valuta bene il costo complessivo delle rate residue in caso di disdetta anticipata.
- Controlla bene come e quando restituire il modem: se non lo restituissi, potresti pagare per “comprarlo” a prezzo elevato (a seconda di quando disdici).
- Se il tuo uso di internet è pesante (molti giga, download grandi), chiedi a TIM se ci sono limiti d’uso “legittimi” nel contratto.
- In fase di recesso, specifica chiaramente nella comunicazione se vuoi pagare subito le rate residue (anziché restarle a rate) - a volte conviene per evitare problemi futuri.

L’indirizzo <indirizzo-abitazione>, <comune> (<provincia>) risulta coperto da FTTH (Fiber To The Home). La FTTH è la tecnologia più stabile che esista perché la fibra arriva fino dentro casa tua, senza tratti in rame o radio.
