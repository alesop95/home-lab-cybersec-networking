# Modem

Fastweb non ha un unico modello universalmente consegnato [https://www.fastweb.it/modem/](https://www.fastweb.it/modem/). Negli ultimi anni ha utilizzato:

*FASTGate* (modello base storico)

*Internet Box NeXXt* per connessioni FTTH fino a 2.5 Gb/s

Ne esistono più modelli con caratteristiche variabili, ma parliamo delle specifiche hardware generali verificate per i modelli più comuni.

Nel progetto il modem in uso è il Seven, descritto nella seconda pagina e, voce per voce di interfaccia, nella cartella sull'[interfaccia del Seven](../06-tbc-i-parametri-di-interfaccia-modem-su-192-168-1-254-rotte/README.md). FASTGate e NeXXt restano come storia della scelta e come confronto: sono i modem con le sole porte LAN da 1 Gbit/s.
