## Suite server di posta elettronica self-hosted

### Mailcow (su-ubuntu-server-24-04/)

Aaa [https://www.raffaelechiatto.com/installazione-e-configurazione-base-di-mailcow-su-ubuntu-server-24-04/](https://www.raffaelechiatto.com/installazione-e-configurazione-base-di-mailcow-su-ubuntu-server-24-04/)

Mailcow è una suite server di posta elettronica self-hosted basata su container Docker che integra componenti open source (Postfix per SMTP, Dovecot per IMAP/POP3, Rspamd per antispam, ClamAV per antivirus, SOGo o altri per webmail/calendari) in un unico ambiente coordinato. Gestisce nomi dominio multipli, account, alias e liste di distribuzione con interfaccia web, offre gestione di certificati TLS e politiche di sicurezza (SPF/DKIM/DMARC). La comunicazione tra servizi avviene via rete interna Docker e volumi persistenti per dati. La configurazione si fa tramite file YAML e pannello web; i container isolano i singoli servizi. Mailcow non è un appliance chiuso, richiede competenze Linux/Docker per manutenzione e aggiornamenti. Non posso verificarlo dal link specifico fornito.
