# OneCommander for Windows

OneCommander is a modern file manager for Windows 11 and Windows 10. Features include tabs, dual-pane browsers, columns navigation, built-in preview, editable themes, color tags, and much more. It is free for home use and no ads [https://www.onecommander.com/](https://www.onecommander.com/).
