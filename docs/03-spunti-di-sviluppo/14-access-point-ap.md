# Access Point (AP)

Per andare al piano sotto dentro predisposizione (?)

Cudy PoE200H supporta:

Standard 802.3af/at → compatibile con access point PoE standard come il Tenda BE5010.

Velocità 2,5 Gbps → compatibile con il tuo switch 2,5 Gbps.

Alimentazione fino a 30 W → sufficiente per un AP Wi-Fi 7 di fascia consumer.

Distanza fino a 100 m → standard Ethernet PoE.

Puoi collegarlo direttamente all’access point senza problemi.
