# Pritunl (with web interface) - open source per gestione centralizzata server VPN

Pritunl [https://pritunl.com/](https://pritunl.com/) è una piattaforma open-source per la gestione centralizzata di server VPN.

Fornisce un layer di orchestrazione e controllo sopra OpenVPN e WireGuard, non è un protocollo VPN a sé.

Espone una web UI per configurare utenti, certificati, routing e policy di accesso.

Utilizza MongoDB come datastore per configurazioni e stato.

Supporta autenticazione locale e integrazioni SSO (LDAP, SAML, OAuth).

È progettato per ambienti enterprise e cloud, con gestione multi-server e alta disponibilità.

Il suo ruolo è semplificare deployment, scalabilità e auditing di infrastrutture VPN.
