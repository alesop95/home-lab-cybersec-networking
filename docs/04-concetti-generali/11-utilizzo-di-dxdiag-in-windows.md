# Utilizzo di dxdiag in Windows

Per accedere al DirectX Diagnostic Tool su Windows, premi il tasto Windows insieme a R, digitare "dxdiag" e premere Invio. Apparirà una finestra che mostra informazioni dettagliate sul sistema, inclusi il sistema operativo, la scheda grafica e il processore, rendendo facile la diagnosi di problemi grafici o audio.
