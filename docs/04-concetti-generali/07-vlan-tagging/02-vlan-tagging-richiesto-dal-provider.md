# VLAN tagging richiesto dal provider

Riguardo il VLAN tagging sulla porta WAN dell’ONT, Fastweb su PM5100-T1 per linee business o casa pro normalmente non richiede il tag VLAN per l’accesso internet. La porta 2,5 GbE dell’ONT espone direttamente il traffico IP pubblico su Ethernet senza necessità di inserire tag VLAN specifici per l’Internet WAN.
